# Sistema Completo de Crescimento no Instagram com IA — Klin (@klin_oficial)

Sistema de criação de conteúdo para o nicho **calçados infantis / maternidade**, construído a partir de dados reais da conta @klin_oficial (472,5 mil seguidores) obtidos via API do Instagram (Composio) + pesquisa de tendências virais 2026.

## Diagnóstico em uma linha

> A conta tem alcance de sobra e engajamento de menos (~0,014%): o mascote e o conteúdo educativo salvável performam 3-8x acima da média, mas não têm sistema. Este sistema transforma esses dois ativos em máquina de crescimento.

## Os 7 pilares do sistema

| Pilar | Métrica-alvo | Frequência semanal |
|---|---|---|
| Educativo (saúde dos pés) | Saves | 3x |
| Humor relatable | Shares | 1-2x |
| Mascote/Trend | Alcance | 1x |
| Emocional | Comentários | 1x |
| Produto disfarçado | Conversão | máx 1x |
| Autoridade/Bastidores | Confiança | 1x |
| UGC/Comunidade | Pertencimento | 1x |

## Como operar

1. **Semana 0:** ler Etapas 1-3; gravar em lote os Reels da Semana 1 (Etapa 4) e montar carrosséis (Etapas 5 + 7).
2. **Diário:** publicar o conteúdo do dia (Etapa 9) + a sequência de Stories correspondente (Etapa 6).
3. **Domingo:** revisar retenção 3s, saves e shares; duplicar o que performou 2x acima da média com gancho novo (Etapa 3).
4. **Cada gravação:** reaproveitar nas 7 plataformas (Etapa 10).
