# Etapa 5 — 20 Carrosséis

Este documento reúne os 20 carrosséis (C01-C20) do Sistema de Crescimento Instagram da **Klin (@klin_oficial)**, seguindo os 7 pilares de conteúdo e o diagnóstico de performance do brief: conteúdo educativo salvável é o formato de carrossel que mais performa na conta, e saves/shares são os sinais mais fortes do algoritmo 2026 para o nicho parental. **Como usar:** cada carrossel traz pilar, objetivo, título de capa (gancho), estrutura slide a slide, CTA final, prompt de imagem IA para a capa e legenda pronta. O slide 1 é sempre a capa-gancho, o penúltimo é o resumo salvável e o último é o CTA. Tom de mãe para mãe, nunca institucional. Conteúdo de saúde sempre com a ressalva "converse com o pediatra".
