# Etapa 3 — 50 Ganchos Que Param o Scroll

Ganchos criados a partir da pesquisa (Etapa 1) para o nicho calçados infantis/maternidade. Uso: fale o gancho nos primeiros 2 segundos **e** coloque-o como texto na tela no primeiro frame. Na legenda, o gancho é sempre a primeira linha (antes do "...ver mais"). Teste 2-3 ganchos diferentes para o mesmo conteúdo.

## Curiosidade

| # | Gancho |
|---|---|
| 1 | Vira o tênis do seu filho agora e olha a sola. Ela conta uma história. |
| 2 | Existe um teste de 5 segundos que revela se esse tênis serve pro seu filho. |
| 3 | Sabe o que acontece com o pé de uma criança dentro de um calçado rígido? |
| 4 | Tem um detalhe na etiqueta desse calçado que ninguém percebe... e ela vira uma planta. |
| 5 | O pé do seu filho cresce mais rápido num mês específico do ano. Adivinha qual? |

## Como usar esta biblioteca

| Regra | Detalhe |
|---|---|
| Combine com a matriz de conteúdo | Cada reel/carrossel das Etapas 4-5 já traz gancho próprio; use esta lista para variações A/B |
| Adapte o formato | Em Reels: falado + texto na tela. Em carrossel: capa. Em Stories: primeira frase do frame 1 |
| Saúde com responsabilidade | Ganchos 6-10, 30, 48-49: sempre fechar o conteúdo com "converse com o pediatra" |
| Meça | Gancho bom = retenção 3s acima de 70% e queda suave; troque o gancho antes de descartar o conteúdo |
